# 分子てつなぎパズル

分子式から原子の「手」をつないで構造式を組み立てる化学パズル

🔗 **公開URL**: https://molecule.meetupsensei.com/

## 概要

表示された分子式（H₂O、NH₃、C₂H₅OH など）をもとに、原子どうしを結合でつないで構造式を組み立てるパズルです。
原子の「手（価標）」をつなぐ結合線モードと、不対電子を出し合って共有電子対をつくる電子式モードを切り替えて遊べます。
完成すると共有電子対・非共有電子対の数を問うクイズと、分子の形や特徴の解説が表示されます。
二原子分子から身近な有機物まで4ステージ＋上級ステージ（SO₂・H₂SO₄・HNO₃）の全20問を収録しています。

## 使い方

- 左のステージ一覧から分子を選ぶ
- 原子をタップし、つなぎたい相手の原子をタップすると単結合ができる
- 結合の線をタップすると、二重結合 → 三重結合 → 外す の順に切り替わる
- 原子はドラッグで自由に動かせる
- すべての手（不対電子）が埋まり、1つの分子になれば完成
- 完成後のクイズに答えて、解説を読む
- 行き詰まったら「ヒントを見る」（段階的に表示）や「答えを見る」を使う
